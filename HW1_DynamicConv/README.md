# HW1 Dynamic Convolution

This homework contains two parts:

1. A dynamic convolution module that can handle variable input channels.
2. A compact image classification network for the course efficiency requirement.

## Files

- `assignment.pdf`: homework statement
- `train.py`: main training entry
- `dynamic_convolution.py`: task A model
- `efficient_network.py`: task B model
- `utils.py`: shared utilities
- `data/`: split files only
- `results/`: logs, plots, and text summaries

## Reproducibility

- The original dataset images are not tracked in this repo.
- Put the downloaded images back under `data/images/` before training.
- The included `train.txt`, `validation.txt`, and `test.txt` keep the original file splits.

## Notes

- The original dependency file was kept as `requirements.txt`.
- Existing plots and logs are preserved as homework artifacts.
